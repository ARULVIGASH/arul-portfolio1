# Arul Vigash — Java Full Stack Developer Portfolio

A React + Vite portfolio with responsive layouts, project cards, skills, resume link, and contact links.

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed in the terminal.

## Add your real profile photo
Copy your own professional headshot into `public/` and name it exactly `profile.jpg`.
The site reads it from `/profile.jpg`. Use a square, clear image for the circular crop.

## Project demo links
The project cards currently show "Live demo not deployed yet" because no public demo URLs were supplied.
After deploying each project, open `src/App.jsx` and set that project's `liveDemoUrl` to the real public URL.
Do not set a demo URL until the app is accessible to visitors.

## Publish changes
Commit and push the updated files to GitHub. Vercel can then redeploy the connected repository automatically.
